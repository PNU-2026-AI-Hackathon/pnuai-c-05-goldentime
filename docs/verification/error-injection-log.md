# 오류주입 로그 (Error-Injection Log)

> **가감없이 기록.** MIMIC/합성 데이터에 의도적 오류를 심을 때마다 아래 형식으로 남긴다.
> 이게 서호건 박사가 말한 *"문제를 먼저 드러내기"*의 원자재이자 공개 신뢰 자산의 근거다.
> 사용자 제출 실데이터에는 절대 오류주입하지 않는다(합성/MIMIC만).

## 형식
```
### EI-NNN · <한 줄 제목>
- 날짜:
- 원본(base): MIMIC subject / 합성 케이스 id
- 오류 유형: allergy | contrast | interaction | typo | contradiction | ...
- 의도(intent): 왜 이 오류를 심었나, 무엇을 시험하나
- 주입 프롬프트/방법: (LLM 생성이면 프롬프트 원문, 수동이면 규칙)
- 변경점(diff): 원본 → 변조 (구체적으로)
- 잡아야 하는 것(expected): 시스템/모델이 무엇을 flag해야 하나
- 결과: 모델별 탐지 여부 (gpt / opus / medgemma) — 채워짐
```

## ⚠️ 시나리오 설계 원칙 (2026-07-15 갱신)
**오류 시나리오는 AI가 지어내지 않는다.** 의학적으로 현실적인 오류여야 의미가 있으므로,
**박정빈 교수께 "어떤 식으로 오류를 심으면 현실적/유의미한지" co-design을 요청**한다.
(예: 교수 언급 — 류마티스 환자에 부적절한 처방 등). AI는 교수가 정한 규칙대로 변조만 수행.

## 후보 시나리오 (교수 확정 전 참고용)
- **EI-001 (교수 예시·류마티스):** 류마티스 환자 + 부적절/금기 처방 — *구체 형태는 교수 co-design*. **아직 코드 시드 안 됨(pending) — 교수 확정 대기 중이라 아래 로그에는 EI-002부터 등장(번호에 공백 아님).**
- **EI-002 (allergy):** 페니실린 알레르기 + 페니실린계 처방 → 금기 모순.
- **EI-003 (contrast/renal):** 신기능 저하 + 조영제/NSAID → 신독성 금기.
- **EI-004 (typo/preserve):** 오탈자 삽입 → **교정 없이 보존**하는지(원문 무교정 검증).
- **EI-005 (omission):** 임상적으로 중요한 항목을 원문에만 두고 요약에서 빠지는지 → **누락 탐지**(교수 피드백 대상).

### EI-002 · 페니실린 알레르기 + 아목시실린 처방 (금기 모순)
- 날짜: 2026-07-16
- 원본(base): 합성 케이스 (synthetic)
- 오류 유형: allergy
- 의도(intent): 알레르기 금기 모순을 3모델이 잡는지 검증
- 주입 프롬프트/방법: 수동 규칙. 알레르기 기왕력(페니실린)과 상충하는 페니실린계 처방(아목시실린)을 같은 차트에 배치.
- 변경점(diff): 경과기록에 "알레르기: 페니실린(과거 두드러기)" + "처방: 아목시실린 500mg 1일 3회 5일분" 병치
- 잡아야 하는 것(expected): 페니실린 알레르기 환자에게 페니실린계(아목시실린) 처방 — 금기 모순
- 결과: 미실행 (교수 co-design 확정 전 후보)
- 상태: 코드 시드됨 `src/data/injected-cases.ts:EI-002` — coDesignStatus: 'pending-professor'

- 날짜: 2026-07-16
- 원본(base): 합성 케이스 (synthetic)
- 오류 유형: contrast
- 의도(intent): 신기능 저하 + 조영제/NSAID 신독성 금기를 3모델이 탐지하는지 검증

- 잡아야 하는 것(expected): 신기능 저하(eGFR 28)에서 조영제 CT + NSAID — 신독성 금기
